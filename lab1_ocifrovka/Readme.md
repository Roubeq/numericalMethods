Математическая модель. 
Необходимо построить математическую модель движения по заданной траектории. За траекторию берется сплайн. 
Система не имеет силы трения и силы сопротивления. (поэтому скорость в каждой точке пространства рассчитывается исходя из начальных условий и не меняется с ходом времени). 
Результат гифка движения точки по траектории.
